Twelve agents that organise files, triage messages, watch pages and pull data out of documents — on a schedule, without you.

How it was built

    
The decisions,
and what they cost.

    
Every tool on this page mirrors something in the codebase. Here's the reasoning behind each, including the parts that went wrong.


    

      

        
Schemas are derived, not written

        
A hand-written JSON Schema drifts the moment you change a function signature, and the failure is silent — the model keeps sending an argument that no longer exists. So @tool reads the type hints and docstring and generates the schema. One source of truth, and the Schema Builder above runs the same rules.

      

      

        
Capabilities are injected, never exposed

        
Every file tool needs to know where the sandbox is, and the model must never get to choose it. ToolRegistry.bind() fills config in before the call while the schema the model sees stays unchanged — there's a test asserting exactly that. The same pattern keeps webhook URLs out of reach: an agent picks a destination name, and the environment supplies the URL.

      

      

        
Errors go to the model, not the stack

        
A tool that raises kills the run. A tool that returns its error becomes feedback the model reads and corrects on the next turn. Bad path, wrong argument type, sandbox violation — all come back as tool_result with is_error: true, and the run survives.

      

      

        
The sandbox compares components

        
Paths are resolved before they're checked, which closes .. and symlinks together. Then Path.relative_to compares components rather than characters — because "/work-evil".startswith("/work") is True, and a prefix check would have let it through. Try it in the Sandbox Tester.

      

      

        
A bug that only existed on macOS

        
The file tools crashed on a Mac and worked on Linux. On macOS /tmp is a symlink to /private/tmp, and the config stored the workspace unresolved while the safety layer always resolved it — two strings for one directory, so relative_to raised. The fix was to normalise once, after applying overrides; normalising before had left every --workspace flag unnormalised. CI now runs macOS and Windows, and a test builds a symlinked workspace explicitly so it can't come back.

      

      

        
Tests that cost nothing to run

        
49 tests, no network and no API key. The agent loop is tested against a scripted fake client, which covers the multi-turn path, error recovery, token accounting and the step ceiling. The whole suite runs in under a tenth of a second, so there's no reason to skip it.
