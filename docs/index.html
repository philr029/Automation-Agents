The project

    

      

        
Automation Agents

        
Twelve agents that organise files, triage messages, watch pages and pull data out of documents — on a schedule, without you.

        
The engine is about forty lines: send the conversation and the tool list, run whatever tools the model asks for, feed the results back, repeat until it stops asking. Everything else is giving it tools and stopping it doing damage.

        

          View on GitHub ↗

        researchermeeting-notescode-reviewer
        daily-digestspreadsheet-cleanerrepurposer
      

    


    
$ git clone https://github.com/philr029/Automation-Agents.git
$ pip install -r requirements.txt
$ cp .env.example .env        # paste your API key

$ python main.py --list
$ python main.py file-organizer          # a rehearsal — changes nothing
$ python main.py file-organizer --apply  # for real

Every run is a rehearsal by default — it tells you what it would do and changes nothing until you add --apply. Agents are locked to one folder you nominate, and there is no general shell tool. Runs on macOS, Linux and Windows.
